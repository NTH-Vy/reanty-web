# Reanty - Real Estate Website

A modern real estate website showcasing properties with a clean, professional design.

## 🚀 Live Demo

[https://reanty-web.netlify.app/](https://reanty-web.netlify.app/)

## 🛠️ Technologies

- **HTML5** - Pure semantic markup
- **CSS3** - Custom styling with modern features (CSS Grid, Flexbox, CSS Variables)

## 📁 Project Structure

```
.
├── index.html          # Main HTML file
├── style.css           # Custom CSS styling
├── images/             # Project images
└── README.md           # Project documentation
```

## ✨ Features

- Responsive design for all devices
- Hero section with property showcase
- Buyer, Renter, and Seller guides
- Featured property listings
- Services section
- Modern UI with smooth animations

## 🎨 Design Highlights

- Clean, professional layout
- Orange (#ff5436) accent color
- Custom SVG icons and graphics
- Smooth hover effects and transitions
